A tenant user's identity token reaches the ingress, which mints a per-agent transaction token and passes it with tenant credentials to the agent in the AgentCore Runtime, the agent presents it to each tools gateway the token's `aud` names (`default` for the `crm` tools, `finance` for the `invoices` tools), each gateway's Policy engine admits the target and its REQUEST interceptor admits the one tool and signs a tenant context for that call, the `finance` gateway's RESPONSE filter trims `tools/list` to the tools the user holds, and the tool verifies that context and reads only that tenant's data. Three trust zones: the ingress alone sees the identity token, the agent is untrusted code holding only tenant-scoped material, and a tool trusts the signed context alone. `IAM` badges mark the walls IAM enforces: the Runtime resource policy, the two KMS key policies, the tenant roles behind the TVMs and the entitlement store's tenant-admin role.
